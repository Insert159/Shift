# Shift File Merger Sorter

[![Java Version](https://img.shields.io/badge/Java-11%2B-blue.svg)](https://www.oracle.com/java/technologies/javase-jdk11-downloads.html)
[![Maven](https://img.shields.io/badge/Maven-3.6%2B-orange.svg)](https://maven.apache.org/)

**Утилита для слияния и сортировки больших файлов с помощью алгоритма внешней сортировки слиянием.**

---

## 📋 О программе

Программа объединяет несколько предварительно отсортированных файлов в один результирующий файл с сохранением порядка сортировки (по возрастанию или убыванию). Поддерживает работу с целыми числами и строками.

**Ключевая особенность:** файлы могут быть любого размера — программа не загружает их целиком в оперативную память, обрабатывая данные порциями.

---

## 🚀 Запуск

### 1. Сборка проекта

    mvn clean package

После сборки в папке `target/` появится файл `shift-sorter.jar`.

### 2. Формат командной строки

    java -jar target/shift-sorter.jar [режим] [тип_данных] выходной_файл входной_файл1 входной_файл2 ...

### 3. Параметры

| № | Параметр | Описание | Обязательный |
|---|----------|----------|--------------|
| 1 | `-a` или `-d` | `-a` — по возрастанию (по умолчанию)<br>`-d` — по убыванию | ❌ Нет |
| 2 | `-i` или `-s` | `-i` — целые числа<br>`-s` — строки | ✅ Да |
| 3 | `выходной_файл` | Путь к файлу, куда будет записан результат | ✅ Да |
| 4..N | `входные_файлы` | Один или несколько файлов для слияния | ✅ Да |

### 4. Примеры запуска

**Целые числа по возрастанию:**

    java -jar target/shift-sorter.jar -i -a result.txt data1.txt data2.txt

**Строки по возрастанию** (режим `-a` можно опустить):

    java -jar target/shift-sorter.jar -s result.txt file1.txt file2.txt file3.txt

**Строки по убыванию:**

    java -jar target/shift-sorter.jar -d -s result.txt input1.txt input2.txt

## 📁 Требования к входным файлам

- **Целые числа (`-i`):** каждая строка содержит одно целое число (например, `-5`, `0`, `12345`)
- **Строки (`-s`):** каждая строка содержит любые **не пробельные** символы (например, `hello`, `world123`)
- Данные записаны **в столбик** (по одному элементу на строку)
- Файлы должны быть **предварительно отсортированы** (в том же порядке, который указан в параметрах)

## ⚠️ Обработка ошибок

Программа устойчива к ошибкам и не "падает". При возникновении проблем происходит частичная обработка:

| Ситуация | Действие программы |
|----------|-------------------|
| Строка с пробелами (для строк) | Строка пропускается, обработка продолжается |
| Нечисловое значение (для чисел) | Строка пропускается, обработка продолжается |
| Нарушен порядок сортировки в исходном файле | Данные после нарушения отбрасываются, остальное обрабатывается |
| Файл не найден | Выводится ошибка, обработка остальных файлов продолжается |
| Не указан ни один входной файл | Программа завершается с сообщением об ошибке |

**Пример вывода предупреждения:**

    Warning: Skipping invalid line in 'data.txt': "abc 123"
    Warning: File 'unsorted.txt' has out-of-order element, truncating from line 15

## 📝 Примечания

- Программа реализует сортировку слиянием **самостоятельно**, без использования встроенных библиотечных функций сортировки
- В коде учтены все возможные пограничные случаи: пустые файлы, один входной файл, очень большие файлы
- Строки с пробелами считаются ошибочными и игнорируются согласно ТЗ
